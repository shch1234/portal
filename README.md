## 脚手架项目

### 创建项目命令  
mvn archetype:generate  -DgroupId=${自定义groupId} -DartifactId=${自定义artifactId}  -Dversion=${自定义版本号} -Dpackage=${自定义包路径} -DarchetypeGroupId=com.weili.framework.example -DarchetypeArtifactId=weili-framework-example-archetype -DarchetypeVersion=1.0.0-SNAPSHOT -DinteractiveMode=false   -X
