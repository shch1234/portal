## 🎯 设计目标

### 1. 核心目标

- ✅ **统一异常处理**：所有任务使用相同的异常处理逻辑
- ✅ **统一日志格式**：所有任务使用相同的日志格式
- ✅ **统一统计收集**：所有任务使用相同的统计信息收集
- ✅ **灵活扩展**：支持可选功能（检查点、分批处理等）
- ✅ **易于使用**：新任务只需关注业务逻辑

### 2. 设计原则

1. **最小侵入**：现有任务可以逐步迁移，不影响现有功能
2. **灵活配置**：支持可选功能，不强制所有任务使用所有功能
3. **向后兼容**：框架不影响现有任务的运行
4. **易于测试**：框架代码易于单元测试

#### BaseScheduledJob（基础任务）

```java
package com.weili.iot_portal.task.framework;

import com.xxl.job.core.context.XxlJobHelper;
import com.xxl.job.core.handler.annotation.XxlJob;
import lombok.extern.slf4j.Slf4j;

/**
 * 定时任务基类
 * 提供统一的异常处理、日志记录、统计收集等功能
 */
@Slf4j
public abstract class BaseScheduledJob {
    
    /**
     * 执行任务逻辑（由子类实现）
     */
    protected abstract JobExecutionResult executeInternal() throws Exception;
    
    /**
     * 任务名称（用于日志）
     */
    protected abstract String getJobName();
    
    /**
     * 执行入口（XXL-Job调用）
     */
    @XxlJob
    public void execute() {
        long startTime = System.currentTimeMillis();
        String jobName = getJobName();
        
        XxlJobHelper.log("开始执行任务: {}", jobName);
        log.info("开始执行任务: {}", jobName);
        
        try {
            JobExecutionResult result = executeInternal();
            long cost = System.currentTimeMillis() - startTime;
            
            // 统一输出统计信息
            outputStatistics(jobName, result, cost);
            
        } catch (Exception e) {
            long cost = System.currentTimeMillis() - startTime;
            handleException(jobName, e, cost);
            throw e; // 让XXL-Job处理重试
        }
    }
    
    /**
     * 输出统计信息
     */
    protected void outputStatistics(String jobName, JobExecutionResult result, long cost) {
        XxlJobHelper.log("任务完成: {}, 成功={}, 跳过={}, 失败={}, 耗时={}ms", 
                jobName, result.getSuccessCount(), result.getSkipCount(), 
                result.getErrorCount(), cost);
        log.info("任务完成: {}, 成功={}, 跳过={}, 失败={}, 耗时={}ms", 
                jobName, result.getSuccessCount(), result.getSkipCount(), 
                result.getErrorCount(), cost);
    }
    
    /**
     * 处理异常
     */
    protected void handleException(String jobName, Exception e, long cost) {
        log.error("任务执行失败: {}, 耗时={}ms", jobName, cost, e);
        XxlJobHelper.log("任务执行失败: {}, error={}", jobName, e.getMessage());
    }
}
```

#### BaseBatchJob（分批处理任务）

```java
package com.weili.iot_portal.task.framework;

import com.xxl.job.core.context.XxlJobHelper;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;

import java.util.List;

/**
 * 分批处理任务基类
 * 适用于需要处理大量数据的任务
 */
@Slf4j
public abstract class BaseBatchJob<T> extends BaseScheduledJob {
    
    @Value("${job.batch.size:50}")
    protected int batchSize;
    
    /**
     * 查询待处理数据
     */
    protected abstract List<T> queryData();
    
    /**
     * 处理单个数据项
     */
    protected abstract ItemProcessResult processItem(T item);
    
    /**
     * 获取数据项的唯一标识（用于日志）
     */
    protected String getItemId(T item) {
        return String.valueOf(item.hashCode());
    }
    
    /**
     * 是否继续处理（用于超时控制）
     */
    protected boolean shouldContinue(long startTime, long timeoutMs) {
        long elapsed = System.currentTimeMillis() - startTime;
        return elapsed < timeoutMs;
    }
    
    @Override
    protected JobExecutionResult executeInternal() throws Exception {
        List<T> dataList = queryData();
        
        if (dataList == null || dataList.isEmpty()) {
            XxlJobHelper.log("未找到待处理数据");
            return JobExecutionResult.empty();
        }
        
        XxlJobHelper.log("待处理数据量: {}", dataList.size());
        
        int successCount = 0;
        int skipCount = 0;
        int errorCount = 0;
        long startTime = System.currentTimeMillis();
        long timeoutMs = 25 * 60 * 1000; // 25分钟超时
        
        // 分批处理
        for (int i = 0; i < dataList.size(); i += batchSize) {
            // 检查超时
            if (!shouldContinue(startTime, timeoutMs)) {
                XxlJobHelper.log("处理超时，已处理: {}/{}, 成功={}, 跳过={}, 失败={}", 
                        i, dataList.size(), successCount, skipCount, errorCount);
                break;
            }
            
            int endIndex = Math.min(i + batchSize, dataList.size());
            List<T> batch = dataList.subList(i, endIndex);
            
            for (T item : batch) {
                try {
                    ItemProcessResult result = processItem(item);
                    if (result.isSuccess()) {
                        successCount++;
                    } else if (result.isSkipped()) {
                        skipCount++;
                    } else {
                        errorCount++;
                    }
                } catch (Exception e) {
                    errorCount++;
                    log.error("处理数据项失败: itemId={}", getItemId(item), e);
                    XxlJobHelper.log("处理数据项失败: itemId={}, error={}", 
                            getItemId(item), e.getMessage());
                    // 继续处理下一个，不中断
                }
            }
        }
        
        return JobExecutionResult.of(successCount, skipCount, errorCount);
    }
}
```

#### CheckpointManager（检查点管理器）

```java
package com.weili.iot_portal.task.framework;

import com.weili.basic.common.util.JsonUtils;
import com.weili.basic.redis.client.RedisClient;
import lombok.Data;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.apache.commons.lang3.StringUtils;
import org.springframework.stereotype.Component;

import java.util.List;
import java.util.concurrent.TimeUnit;

/**
 * 检查点管理器
 * 提供检查点的保存、加载、清除功能
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class CheckpointManager {
    
    private final RedisClient redisClient;
    private static final String CHECKPOINT_PREFIX = "job:checkpoint:";
    private static final long DEFAULT_TTL_SECONDS = 24 * 3600; // 24小时
    
    /**
     * 保存检查点
     */
    public <T> void saveCheckpoint(String jobName, String key, List<T> processedItems) {
        String redisKey = buildKey(jobName, key);
        CheckpointData<T> data = new CheckpointData<>();
        data.setProcessedItems(processedItems);
        data.setLastUpdateTime(System.currentTimeMillis() / 1000);
        
        try {
            redisClient.set(redisKey, JsonUtils.toJsonString(data), 
                    DEFAULT_TTL_SECONDS, TimeUnit.SECONDS);
            log.debug("保存检查点: key={}, processedCount={}", redisKey, processedItems.size());
        } catch (Exception e) {
            log.error("保存检查点失败: key={}", redisKey, e);
        }
    }
    
    /**
     * 加载检查点
     */
    public <T> CheckpointData<T> loadCheckpoint(String jobName, String key, Class<T> itemType) {
        String redisKey = buildKey(jobName, key);
        try {
            String value = redisClient.get(redisKey);
            if (StringUtils.isBlank(value)) {
                return null;
            }
            // 使用 TypeReference 处理泛型
            return JsonUtils.parseObject(value, 
                    com.fasterxml.jackson.core.type.TypeReference.forType(
                            com.fasterxml.jackson.databind.type.CollectionType.construct(
                                    java.util.List.class,
                                    com.fasterxml.jackson.databind.type.SimpleType.constructUnsafe(itemType)
                            )
                    ));
        } catch (Exception e) {
            log.error("加载检查点失败: key={}", redisKey, e);
            return null;
        }
    }
    
    /**
     * 清除检查点
     */
    public void clearCheckpoint(String jobName, String key) {
        String redisKey = buildKey(jobName, key);
        try {
            redisClient.delete(redisKey);
            log.debug("清除检查点: key={}", redisKey);
        } catch (Exception e) {
            log.error("清除检查点失败: key={}", redisKey, e);
        }
    }
    
    private String buildKey(String jobName, String key) {
        return CHECKPOINT_PREFIX + jobName + ":" + key;
    }
    
    @Data
    public static class CheckpointData<T> {
        private List<T> processedItems;
        private long lastUpdateTime;
    }
}
```

#### BaseCheckpointBatchJob（支持检查点的分批任务）

```java
package com.weili.iot_portal.task.framework;

import com.xxl.job.core.context.XxlJobHelper;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;

import java.util.HashSet;
import java.util.List;
import java.util.Set;
import java.util.stream.Collectors;

/**
 * 支持检查点的分批处理任务基类
 */
@Slf4j
@RequiredArgsConstructor
public abstract class BaseCheckpointBatchJob<T> extends BaseBatchJob<T> {
    
    protected final CheckpointManager checkpointManager;
    
    /**
     * 构建检查点Key（由子类实现）
     */
    protected abstract String buildCheckpointKey();
    
    /**
     * 获取数据项的唯一标识（用于检查点）
     */
    protected abstract String getItemId(T item);
    
    @Override
    protected JobExecutionResult executeInternal() throws Exception {
        // 加载检查点
        String checkpointKey = buildCheckpointKey();
        CheckpointManager.CheckpointData<String> checkpoint = 
                checkpointManager.loadCheckpoint(getJobName(), checkpointKey, String.class);
        
        Set<String> processedIds = checkpoint != null 
                ? new HashSet<>(checkpoint.getProcessedItems())
                : new HashSet<>();
        
        // 查询数据
        List<T> allData = queryData();
        
        // 过滤已处理的数据
        List<T> remainingData = allData.stream()
                .filter(item -> !processedIds.contains(getItemId(item)))
                .collect(Collectors.toList());
        
        if (remainingData.isEmpty()) {
            XxlJobHelper.log("所有数据已处理，清除检查点");
            checkpointManager.clearCheckpoint(getJobName(), checkpointKey);
            return JobExecutionResult.empty();
        }
        
        if (checkpoint != null) {
            XxlJobHelper.log("从检查点恢复: 已处理={}, 剩余={}", 
                    processedIds.size(), remainingData.size());
        }
        
        // 处理剩余数据
        int successCount = 0;
        int skipCount = 0;
        int errorCount = 0;
        List<String> newProcessedIds = new ArrayList<>();
        long startTime = System.currentTimeMillis();
        long timeoutMs = 25 * 60 * 1000;
        
        for (int i = 0; i < remainingData.size(); i += batchSize) {
            if (!shouldContinue(startTime, timeoutMs)) {
                XxlJobHelper.log("处理超时，保存检查点");
                break;
            }
            
            int endIndex = Math.min(i + batchSize, remainingData.size());
            List<T> batch = remainingData.subList(i, endIndex);
            
            for (T item : batch) {
                try {
                    ItemProcessResult result = processItem(item);
                    String itemId = getItemId(item);
                    
                    if (result.isSuccess()) {
                        successCount++;
                        newProcessedIds.add(itemId);
                        processedIds.add(itemId);
                    } else if (result.isSkipped()) {
                        skipCount++;
                    } else {
                        errorCount++;
                    }
                } catch (Exception e) {
                    errorCount++;
                    log.error("处理数据项失败: itemId={}", getItemId(item), e);
                }
            }
            
            // 每批处理完后更新检查点
            if (!newProcessedIds.isEmpty()) {
                List<String> allProcessedIds = new ArrayList<>(processedIds);
                checkpointManager.saveCheckpoint(getJobName(), checkpointKey, allProcessedIds);
                newProcessedIds.clear();
            }
        }
        
        // 如果所有数据都处理完成，清除检查点
        if (processedIds.size() >= allData.size()) {
            checkpointManager.clearCheckpoint(getJobName(), checkpointKey);
        }
        
        return JobExecutionResult.of(successCount, skipCount, errorCount);
    }
}
```

| 任务类型 | 重构前代码行数 | 重构后代码行数 | 减少比例 |
|---------|--------------|--------------|---------|
| 简单任务 | ~50行 | ~20行 | 60% |
| 分批任务 | ~150行 | ~50行 | 67% |
| 检查点任务 | ~250行 | ~80行 | 68% |

### 维护成本

- **修改异常处理逻辑**：从修改N个任务 → 修改1个基类
- **统一日志格式**：从修改N个任务 → 修改1个基类
- **新增功能**：从实现N次 → 实现1次

### 开发效率

- **新任务开发**：从2-3小时 → 30分钟
- **代码审查**：更容易发现异常处理遗漏
- **测试**：框架代码统一测试，减少重复测试

---

## 🎯 结论

**强烈建议抽取公共框架**，理由：

1. ✅ **代码重复度高**：异常处理、统计、日志模式100%相同
2. ✅ **维护成本高**：修改需要改多个地方
3. ✅ **开发效率低**：每次都要实现相同的异常处理
4. ✅ **容易遗漏**：容易忘记异常处理或统计信息
5. ✅ **未来扩展**：计划中的任务可以直接使用框架

**实施策略**：
- 采用**渐进式重构**，不影响现有任务
- 新任务直接使用框架
- 旧任务逐步迁移（可选）
