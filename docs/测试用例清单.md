## 📋 文档说明

本文档详细列出了Portal端Webhook接收功能的所有测试用例，按照功能模块组织，包含单元测试、集成测试和端到端测试。

**测试覆盖范围**：
- ✅ Webhook接收与安全验证
- ✅ 设备匹配与幂等性
- ✅ 收件箱处理与异步Worker
- ✅ 各类事件处理器（状态、产量、报警、轴坐标、刀具、程序等）
- ✅ 实时数据缓存
- ✅ 定时任务（汇总、补偿）

### 16.2 测试工具脚本

**Webhook签名生成脚本**（Python）：
```python
import hashlib
import time
import random
import string

def generate_signature(token, timestamp, nonce, message_body):
    arr = [token, str(timestamp), nonce, message_body]
    arr.sort()
    joined = ''.join(arr)
    return hashlib.sha256(joined.encode('utf-8')).hexdigest()

# 使用示例
token = "your-webhook-token"
timestamp = int(time.time() * 1000)
nonce = ''.join(random.choices(string.ascii_letters + string.digits, k=12))
message_body = '{"messageId":"xxx","deviceCode":"M001"}'
signature = generate_signature(token, timestamp, nonce, message_body)
```
